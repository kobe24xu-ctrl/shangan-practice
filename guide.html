使用说明

最后更新：2026-11-02 · 对应版本 v1.0

一、打开方式

1. 双击打开（最省事）

进入项目里的 app/ 目录，双击 index.html。题库会正常加载，答题、判分、错题、统计都能用，记录保存在浏览器本地。

这种打开方式下浏览器会拦截跨域请求，AI 功能不可用，页面里会给出提示。

2. 本地服务（AI 可用）

需要 Node.js 18 或更高版本。在项目根目录执行：

node server.js

然后打开 http://localhost:8787。AI 请求会走本地代理，不受浏览器跨域限制。

3. 手机访问（同一 Wi-Fi）

电脑上这样启动，让服务监听局域网：

HOST=0.0.0.0 node server.js

用 ipconfig 查电脑的 IPv4 地址（例如 192.168.1.23），手机浏览器打开 http://192.168.1.23:8787。电脑要保持开机。

二、做题与记录

  • 练习页：选模块、知识点、难度、题量，再选练法。不选知识点就练该模块全部。
  • 答题：选完立即判分（可在设置里关掉），解析下面能记错因和笔记。
  • 错题本：做错自动进来，按错因筛选；点“已掌握”才移出。
  • 收藏：题目右上角星标，收藏页可整组重练。
  • 模考：按模块比例组卷，倒计时、答题卡、交卷判分、模块报告。
  • 统计：近 14 天题量、模块正确率、错因分布、知识点掌握度。

键盘操作：A/B/C/D 选项，← → 切题。

三、配置 AI

设置 → AI 模型，有两种接法，随时可切换。

A. 自带 API 密钥

填四项即可：

字段说明示例
接口地址OpenAI 兼容的 Base URL，末尾不要带 /chat/completionshttps://api.deepseek.com/v1
模型名称服务商文档里的模型 IDdeepseek-chat
API 密钥只存本机浏览器，不写入源码sk-…
价格输入/输出“元/百万 tokens”，用于费用估算2 / 8

填完点“测试连接”。密钥不要发到聊天里，也不要提交到代码仓库。

B. WorkBuddy 云模型（积分）

不用密钥，消耗你 WorkBuddy 账号的应用额度。前提是这个项目已经发布成应用并开通云服务，然后：

  1. 在云服务面板复制 endpoint 和 publishableKey（wbpk_ 开头）；
  2. 打开发布后的域名（不是 localhost）；
  3. 设置 → AI 模型 → WorkBuddy 云模型，填入两个值；
  4. 点“拉取模型列表”，选一个模型。
云服务按 Origin 精确匹配，localhost 和 file:// 会被拒绝，报 auth_ 错误。这是服务端规则，不是页面 bug。

云模型只支持流式输出；SDK 不提供余额、额度、账单查询，页面只累计展示单次返回的 credit。额度用完会报 quota_，重试无效。

成本控制

  • 普通刷题不调用模型，题库自带解析；只有点“问 AI”才发请求。
  • 每次发送前显示预估 tokens 与费用（自带密钥模式）。
  • 每日调用上限，两种模式都生效。
  • 对话只带最近 10 轮上下文。

四、备份与恢复

记录存在浏览器的 localStorage，键名 sas.state.v1。清缓存、换浏览器、换设备都会丢，所以：

  • 导出备份：设置 → 导出学习备份，得到 JSON（含记录、错题、收藏、笔记、设置；不含密钥）。
  • 导入备份：设置 → 导入备份，会覆盖当前记录，有二次确认。
  • 建议：每学一周导一次，文件放网盘或发给自己。

五、导入题库

设置 → 导入题库，选一个 JSON。最小结构：

{
  "questions": [{
    "id": "my-001",
    "module": "ziliao",
    "point": "zl-bz",
    "difficulty": 2,
    "stem": "题干，可含 HTML",
    "options": ["A", "B", "C", "D"],
    "answer": 2,
    "explain": "解析",
    "optionNotes": ["A错在哪", "B错在哪", "C对在哪", "D错在哪"],
    "review": { "status": "pending", "note": "自建题，待审核" }
  }]
}

answer 是选项下标（0 = A）。同一份文件还可以带 points 和 materials，导入后会并入知识图谱。非法条目会被跳过并提示，不会污染题库。

六、常见问题

页面空白 / 提示题库未加载

确认 app/data/bank.js 与 app/index.html 的相对位置没变。如果是从压缩包里单独拖出 index.html，题库会找不到。

AI 提示“直连失败（CORS）”

浏览器不允许网页直接调多数模型服务。用 node server.js 启动后访问 http://localhost:8787，或把请求方式改成“只走代理”。

云模型报 auth_

当前域名不是这个应用的发布域名，或云服务没开通。换成发布后的网址再试。

手机能打开但记录不同步

记录是按浏览器存的，手机和电脑各一份。用导出/导入备份迁移，或等以后加账号同步。

想加题 / 改解析

改 tools/ 里的数据文件，运行 python build.py 重新生成题库；它会做一致性校验和计算题复算。也可以直接用导入题库功能加题。

七、已知限制

  • 题库 104 题，够起步，不够刷到考前；需要继续扩。
  • 常识、政治理论只到摘要级，题目少；申论未纳入。
  • 没有视频字幕，知识点按讲义结构与视频摘要整理，不是逐字稿。
  • 手机只做了浏览器适配，没有原生 App；iOS 上 file:// 的本地存储策略更严，建议用局域网或发布地址。
  • 课程、讲义、真题版权归原机构；题目为原创模拟题，当前仅限个人学习，不得商用。
